### ✨ Features

- 🔐 **Authentication** — Secure sign-in and role-based access
- 📝 **Assessments** — Create and manage technical tests
- 👨‍💼 **Recruiter Dashboard** — Manage questions and invite candidates
- 💻 **Candidate Workspace** — Take timed assessments and track scores
- 📊 **Results & Analytics** — Review assessment performance
- 🛡️ **Admin Panel** — Manage users and monitor activity
- 🌙 **Responsive UI** — Modern interface with theme support

### 🛠️ Tech Stack

**Frontend:** Next.js · React · TypeScript · Tailwind CSS

**Backend:** Node.js · Express · Prisma · PostgreSQL · Redis

### ⚡ Getting Started

```bash
git clone https://github.com/mca-programmer/DevAssess.git
cd DevAssess
npm install
```

Create a `.env.local` file:

```env
NEXT_PUBLIC_API_BASE_URL=http://localhost:5000/api/v1
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
